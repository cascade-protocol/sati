# API Reference

SATI provides two SDK packages at different abstraction levels.

## [@cascade-fyi/sati-agent0-sdk](/reference/sati-agent0-sdk)

Agent0-compatible adapter. Friendly API for agent registration, feedback, search, and reputation. **Start here** unless you need low-level access.

```bash
pnpm add @cascade-fyi/sati-agent0-sdk
```

## [@cascade-fyi/sati-sdk](/reference/sati-sdk)

Low-level SDK for direct access to SATI's Solana program - raw attestations, custom schemas, compression, and encryption.

```bash
pnpm add @cascade-fyi/sati-sdk
```
